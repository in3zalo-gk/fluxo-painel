# Fluxo — Painel de pedidos

Demo estática e standalone de uma operação de pedidos fictícia.

## Recursos
- Interface escura com detalhes em ciano e layout responsivo.
- Busca e filtro por status.
- Criação local com validação e avanço de status.
- Resumo atualizado na tela; sem backend, login, coleta ou armazenamento.

Abra `index.html` em um navegador moderno.
